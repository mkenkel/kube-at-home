Many *arr images run as root, so Phase 5 app namespaces should enforce `baseline` and only warn on `restricted`. Recommended plan: label the clean namespaces now, skip a cluster-wide default-deny (it could cut off DNS, the Gateway or monitoring and there are no apps to protect yet), and add per-namespace network policies in Phase 5 starting with the two public apps (default-deny, allow ingress from the Gateway, allow DNS egress, allow Prometheus scrapes). Their purpose: a compromised exposed app could otherwise reach the unauthenticated Longhorn UI, Prometheus, Alertmanager, the etcd metrics port and every other app.
